Before you begin

Beta requirements

  • A Mac running macOS 27 or later
  • Apple’s TestFlight app and an accepted TimeCode Assistant invitation
  • An unprotected local audio file for analysis
  • For direct export: an ETC Eos console on the same network with OSC enabled

Quick answers

Common questions

Why won’t my track open?

Make sure the file is stored locally and is not protected by digital rights management. If it is in cloud storage, download it before opening it in TimeCode Assistant.

Why can’t TimeCode Assistant reach Eos?

Confirm the Mac and console are on the same network, OSC is enabled in Eos, and the host and TCP port in TimeCode Assistant match the console. Also allow Local Network access when macOS asks.

Will an import overwrite my show?

TimeCode Assistant inspects the selected Event List, blocks overlapping track ranges, preserves existing events and checks the result after import. Keep a current backup of any show file while testing beta software.

Where are my projects stored?

You choose the location when you save a .tmcproj file. TimeCode Assistant also keeps a local recovery copy so an interrupted session can be restored.
